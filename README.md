# 🎵 Spotify Clone (Vercel)

A sleek, responsive Spotify clone built with modern web technologies and deployed on [Vercel](https://vercel.com). Stream music, explore playlists, and enjoy a Spotify-like UI.

## 🔗 Live Demo

👉 [Live Site on Vercel](https://spotify-clone-sable-nine.vercel.app)

## 🚀 Tech Stack

- **HTML5** 
- **CSS** 
- **Vanilla JavaScript** 
- **Vercel** 



## 🛠️ Setup Instructions

```bash
# 1. Clone the repo
git clone https://github.com/ankurashish/spotify-clone-vercel.git

# 2. Navigate into the project
cd spotify-clone-vercel

# 3. Install dependencies
npm install

# 4. Run the development server
npm run dev
```



## 📌 Features

- Spotify-style layout & navigation
- Responsive design
- Music controls UI 
- Animated sidebar and transitions
